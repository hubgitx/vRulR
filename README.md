# vRulR - the virtual ruler

![vRulR](vrulr.png?raw=true)

A virtual measuring tool written in Java (use the F1 key to get some help about keyboard shortcuts).


## Requirements
- Java 11 or later

## Build
Using Apache Ant, simply go to the project's base directory (the one where the ant build file 'build.xml' resides) and execute
``` 
ant
``` 

## Run
Run vRulR
```
java -Xmx24m -Xms16m -jar vrulr-<version>.jar
```
